# Kushank Kashyap — Portfolio Website

A responsive, single-page professional portfolio for Data Analytics, Business Analysis and Business Intelligence roles.

**Live site:** https://kushankkashyap.github.io/  
**GitHub profile:** https://github.com/Kushankkashyap  
**LinkedIn:** https://www.linkedin.com/in/kushankkashyap/

## What the site covers

- Professional summary and analytics workflow
- Experience across US Healthcare RCM, reporting and business analysis
- Featured projects: ProfitTrace, Healthcare RCM and HR People Analytics
- SQL Server, Power BI, DAX, Excel and business analysis skills
- Contact and professional links

## Implementation

- HTML and CSS in a single `index.html` file
- Responsive layout for smaller screens
- No JavaScript framework or build step required
- Hosted with GitHub Pages

## Accuracy note

Project datasets and results are described as portfolio case studies where applicable. Experience dates and quantified outcomes should be kept consistent with the candidate's resume and verifiable work history.

## Local preview

Open `index.html` in a browser. The site uses Google Fonts for typography; if offline, the browser will fall back to system sans-serif fonts.
